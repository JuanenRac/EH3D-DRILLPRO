# Support

* **Questions and ideas:** open an issue with the form that fits.
* **A file that does not load:** attach it (or the smallest one that shows the problem) and the message the program gave.
* **Protocol questions:** see `docs/PROTOCOL.md` first. If you have a logic analyser or a serial capture of the original software talking to its control unit, that is the most useful thing you can share.

This is a one-person project and the program is at its first steps: answers can take a few days.
